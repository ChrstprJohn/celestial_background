# Landing artwork

`galaxy.webp`, `moon.webp`, `moon-match.webp`, `age.webp`, `builder.webp`, `planets.webp`, and `gravity.webp` are WebP captures of Celestial's existing rendered discovery-card artwork. They let the homepage show the same subjects without constructing canvases, generating terrain, or downloading planet textures during scrolling. Desktop hover still opens the original live preview.

The Moon rendering uses the bundled Moon map documented by its existing source link. The builder and planet rendering use the Solar System Scope textures documented in `../textures/planets.source.json` (CC BY 4.0). Generated galaxy/orbit/gravity scenes are illustrative artwork. `showcase.webp` is a compressed 960×540 derivative of the existing `brag-output/brag.jpg` video poster.

Card source captures are stored in ignored `test-results/card-*.png`; no source texture files were replaced.
